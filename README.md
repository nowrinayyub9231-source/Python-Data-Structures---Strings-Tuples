# Python-Data-Structures---Strings-Tuples
A beginner-level Python exercise set covering two of the language's core built-in data structures — **strings** and **tuples**. This project demonstrates fundamental operations including concatenation, slicing, indexing, string methods, and tuple manipulation, laying groundwork for data cleaning and transformation tasks used in analytics work.

## 📋 Overview

This repository is divided into two main sections:

- **Strings** – concatenation, slicing/indexing, and built-in string methods
- **Tuples** – creation, concatenation, repetition, and element access

## 🗂️ Contents

### 1. String Concatenation
- Take user input (name) and concatenate it with a greeting string (`"Hello "`)
- Further concatenate a welcome message to the existing string

### 2. String Slicing and Indexing
Using the concatenated string from above:
- Print the first character
- Print the last character
- Print the first 5 characters
- Print the last 11 characters
- Print the string reversed
- Slice out the word `"Python"`

### 3. String Methods
Using `strM = "Python beginner tutorial"`:
- Convert to uppercase
- Convert to lowercase
- Capitalize (restore original form)
- Count occurrences of the character `'t'`
- Replace `"Python"` with `"Machine Learning"`

### 4. Tuples — Creation, Modification, and Access
Using `T1 = (10, 20, 30)` and `T2 = (40, 50, 60)`:
- Concatenate `T1` and `T2` into `t_combine`
- Repeat the elements of `t_combine` 3 times
- Access the 3rd element of `t_combine`
- Access the first three elements of `t_combine`
- Access the last three elements of `t_combine`

## 🛠️ Requirements

- Python 3.x
- No external libraries required

## ▶️ How to Run

```bash
python assignment1.py
```

## 🎯 Learning Objectives

- Understand string immutability and manipulation techniques
- Practice indexing and slicing syntax (positive/negative indices)
- Apply common built-in string methods
- Understand tuple immutability and how it differs from lists
- Practice sequence operations (`+` for concatenation, `*` for repetition, `[]` for indexing/slicing)
